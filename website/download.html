Verify what you downloaded

Every file is published with its SHA-256. Compare it before you install — especially if the file travelled by USB or chat.

Check on Windows

In PowerShell, in the download folder:

Get-FileHash .\Agent-Mark-Hub-0.1.0-x64-setup.exe -Algorithm SHA256

The hash must match exactly. If it does not, delete the file and download again.

System requirements

  • OS: Windows 10 or Windows 11, 64-bit
  • Memory: 4 GB (8 GB comfortable)
  • Disk: about 150 MB installed, plus backups
  • Display: 1280 × 800 or larger recommended for reports
  • Rights: none for the .exe; administrator for the MSI
  • Network: not required after install

What is in the box

  • The full offline hub: roster, scores, flags, comments, reports, backup, audit
  • Six synthetic demo students to explore with
  • Ed25519 signing key generated on first run, stored locally
  • No account, no licence server, no telemetry
  • Uninstaller that removes the program (your data folder is left for you to delete)
