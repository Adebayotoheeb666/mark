Everything a term needs, none of the cloud.

Six deterministic steps from roster to a signed report card. Every rule has an ID, every action lands in the audit log.

Roster import

Bring students in by CSV with a dry run first. Duplicate IDs are reported and nothing is written until you say so.

Score capture

Range checks, duplicate detection and missing-score flags. A score is never silently overwritten, and a flag never changes a mark.

Two-person approval

Drafts are reviewed by the class teacher, then the head. Locking re-hashes the payload and signs it — no approval, no signature.

Report cards

Print sheets with subject averages, grades and positions. Unapproved cards carry a red DRAFT — NOT OFFICIAL banner.

Encrypted backup

Backups are sealed with XChaCha20-Poly1305 and a manifest. A restore drill must pass before the term can go live.

Audit trail

Each action hashes the previous one. Editing history breaks the chain, and the checker script tells you exactly where.

Built for trust

No model. No API key. No upload.

Agent Mark is deliberately unexciting technology: fixed rules, local files, real signatures. That is the point — a report card should be reproducible years later.

Read the privacy note or the technical decisions behind it.

  • No AI or MLNo model, no inference, no training data. Grades come from arithmetic you can check by hand.
  • Offline by defaultWorks with the network cable unplugged. There is no relay account to create.
  • Local databaseSQLite in the school's own AppData folder. Delete the folder for a factory reset.
  • Real signaturesEd25519 over the exact report payload, verifiable with a public key.
  • Sealed backupsBackup files contain no readable names, classes or marks.
  • Provable historyAn offline checker re-verifies the audit chain and every locked report.

A term, in three sittings.

Questions schools ask

Does it need the internet?

No. The app is fully offline. The installer bundles Microsoft's WebView2 bootstrapper in case the PC has never had Edge; after that, nothing is downloaded. No licence check, no telemetry.

Where does student data live?

In a SQLite database under %APPDATA%\org.agentmark.hub\agent-mark-hub\ on that PC, plus encrypted backup files you choose to create. Nothing is uploaded, because the app has no network client.

Is there an AI feature?

No. Comments are chosen from a reviewed bank and edited by a teacher. Grades are weighted arithmetic with fixed grade bands. There is no model, no API, and no data collection.

Can teachers use a phone?

Yes — there is an installable mobile app that runs in the phone browser and works offline. It is a companion preview: capture and check scores, preview a card, keep data on the device. The authoritative hub stays on the school PC.

Is it ready for real students?

Not yet. This is a pilot build: use synthetic data until an external security review closes the open findings. Details.
