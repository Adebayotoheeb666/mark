## 2. Immediate containment (first hour)

- [ ] Stop using the affected PC/phone; lock the hub and Windows session.
- [ ] If malware or unauthorized access is suspected, disconnect from the network but keep the
      device powered for evidence.
- [ ] Do not delete the data folder, backups, exports, browser history, or audit log.
- [ ] Identify who had access and which accounts/passphrases/recovery codes may be exposed.
- [ ] Notify the Head, DPO/counsel, and hub admin.
- [ ] Record the time, reporter, device, location, and initial facts.

The DPO/counsel decides whether the NDPC, parents/guardians, students, or others must be notified and
within what statutory/regulatory timeline. Do not make that decision alone, and do not promise a
timeline until counsel confirms it.

## 4. Recovery

- [ ] Rebuild on a clean, patched PC if compromise is suspected.
- [ ] Restore from a verified backup; verify counts and audit chain; run a drill.
- [ ] Rotate every account password; replace the recovery code if exposed.
- [ ] Destroy exposed exports/backups under the retention/legal-hold decision.
- [ ] Re-enable real mode only after the Head/DPO approve.
- [ ] Monitor for recurrence.

## 5. Notification and records

- [ ] DPO decision recorded, with reasons.
- [ ] Regulator notification (if required): date/time/reference.
- [ ] Data-subject notification (if required): method/date.
- [ ] Staff briefing and support arranged.
- [ ] Incident log completed: facts, timeline, decisions, notifications, remediation.
- [ ] Lessons learned and control changes assigned with owners/dates.
- [ ] Evidence retained securely for the school's required period.
