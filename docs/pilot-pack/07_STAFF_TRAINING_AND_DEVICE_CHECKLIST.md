# Staff Training and Device Hardening Checklist

Every staff member with a hub account completes this before real data is loaded. The hub admin
completes the device section with school IT.

## A. Staff training

- [ ] I have a personal account and will not share my password or use another person's login.
- [ ] I know how to lock the hub and the Windows session when leaving the desk.
- [ ] I know the 15-minute idle lock and the failed-attempt backoff.
- [ ] I know how to enter a score, and that a conflicting entry is refused rather than overwritten.
- [ ] I know how to correct a score with an 8+ character reason; corrections are audited.
- [ ] I know never to delete/re-enter a score to hide a correction.
- [ ] I know my role limits: a teacher approves the draft, a head approves the reviewed report and
      locks/signs, and admin cannot approve.
- [ ] I know to verify a report's fingerprint out-of-band if there is a dispute.
- [ ] I know how to export a student's data and that exports are personal data.
- [ ] I know never to send real data by personal email, WhatsApp, or unapproved cloud storage.
- [ ] I know how to report a lost device, suspected disclosure, or wrong-recipient export immediately.
- [ ] I know the school's data-subject request contact and incident contact.
- [ ] I have read the privacy notice and the pilot stop conditions.
- [ ] I will use only school-approved devices and will not install the app on a personal phone for
      real data unless the school has authorized that device.

## B. Device hardening (hub admin + IT)

- [ ] BitLocker enabled on the system drive; recovery key escrowed by the school.
- [ ] Windows 10/11 supported and fully patched.
- [ ] Antivirus/EDR active and updating.
- [ ] Daily work uses a standard Windows account; local admin only for install/update.
- [ ] Screen lock on idle; strong Windows password/PIN; no shared Windows account.
- [ ] No personal cloud-sync folder contains the data directory or backups.
- [ ] Backup media encrypted and stored under school control.
- [ ] Physical lock/secure storage for the PC and backup media.
- [ ] WebView2 runtime current.
- [ ] App version and artifact hash recorded.
- [ ] Recovery code printed, sealed, and stored off the PC.
- [ ] Test restore/drill completed and filed.
- [ ] Old/unused staff accounts removed.
- [ ] Mobile (if used): device passcode/biometric lock, encryption enabled, app passcode set,
      auto-lock on, no screenshots, remote-wipe capability documented.

## C. Acknowledgement

I have completed the training and understand the rules above. I will report incidents immediately.
